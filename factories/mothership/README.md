# Mothership Factory

Mothership is the control-plane factory for `recallnet/astrochicken`.

## Environment contract

- Factory env contract: `factories/mothership/env.contract.json`
- Generated example: `factories/mothership/.env.example`

`factories/mothership/.env.example` is generated from the checked-in env
contracts and is the canonical operator bootstrap surface for mothership-local
runtime configuration.
