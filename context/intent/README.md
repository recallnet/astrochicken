# Intent Samples

This directory contains sample intent documents used by tests and docs.

## Files

- `base.intent.json` — baseline intent payload.
- `profiles.intent.json` — separate sample intent with profile-specific overrides (distinct intent id).
- `patch.intent.json` — JSON patch operations applied to the base intent.
- `patch.expected.json` — expected result after applying the patch.
- `default.intent.json` — default intent metadata used when no repo-specific intent is configured.
